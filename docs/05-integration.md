# 05 — 四元素如何協同

> 這四個元素不是獨立的。它們互相強化。
> 其中一個失敗,整個作品的論證就會崩塌。

## 1. 協同關係

```
Ghost 的扁平性
    ↓
讓使用者察覺「我的數位足跡很有限」
    
    
第二幕的冷感
    ↓
讓使用者察覺「我是可量化的」


隱私的真實性
    ↓
讓使用者信任作品,因此接受前兩個揭露


結尾的留白
    ↓
讓前三個揭露在使用者腦中持續發酵
```

## 2. 任一元素失敗,作品如何崩塌

### 如果 Ghost 太深刻
→ 變成 Replika,沒有諷刺
→ 使用者覺得「AI 真懂我」,作品的批判性消失

### 如果 Ghost 太空洞
→ 變成爛 chatbot
→ 使用者覺得「沒什麼」,作品的衝擊消失

### 如果文案太煽情
→ 變成 BuzzFeed,沒有重量
→ 觀眾啟動防衛機制,作品的論證失效

### 如果文案太說教
→ 把答案餵給觀眾
→ 觀眾反抗你的詮釋,作品的諷刺反彈

### 如果隱私是表演
→ 作品自我矛盾
→ 「批判資料剝削的作品在剝削資料」,作品破產

### 如果結尾塞太多
→ 觀眾不會自己想
→ 變成 listicle,作品的餘韻消失

## 3. 共同特徵:克制

**這四個元素的共同特徵是「克制」。**

| 元素 | 克制的是什麼 | 為什麼要克制 |
|---|---|---|
| Ghost | 克制深刻 | 才能扁平,才能證明數位殘骸的有限 |
| 文案 | 克制評價 | 才能冷,才能讓觀眾自己連結 |
| 架構 | 克制收集 | 才能可信,才能讓作品的批判成立 |
| 結尾 | 克制總結 | 才能留白,才能讓觀眾帶走疑問 |

## 4. Black Mirror 的祕密

Black Mirror 之所以是 Black Mirror,**不是因為它戲劇化,是因為它克制**:

- 沒有炫技的視覺效果
- 沒有戲劇性的配樂
- 沒有反派的演講
- 沒有最後的道德教訓

它只是讓事件發生,讓觀眾自己感受。

**你的專案要走這條路。**

## 5. 動手前的自檢清單

在開始 coding 前,問自己這四個問題:

- [ ] 我有能力做出「夠像、但又透露破綻」的 Ghost 嗎?
      (如果還沒驗證過 prompt,先去做)
- [ ] 我有耐心讓文案保持冷感、不評價嗎?
      (如果忍不住想加「警示」或「反思題」,先處理這個衝動)
- [ ] 我願意走 Anthropic ZDR 商業流程嗎?
      (如果不願意,作品的隱私承諾就不誠實)
- [ ] 我願意讓結尾「什麼都不給」嗎?
      (如果忍不住想加 CTA、分享按鈕、延伸閱讀,先處理)

**四個都是「是」,才開始做。**

任何一個是「不是」或「我覺得加一點沒關係」——
作品的力量會在那個點被稀釋。

## 6. 開發順序建議

不是隨便挑一個元素開始。**先驗證最難的**。

### Phase 1:Ghost prompt 驗證(無 UI)
- 用 Anthropic API + curl 或 Python script
- 拿自己的資料生成 prompt
- 跑 12 題標準測試
- 三人盲評
- **這階段不過,後面不必做**

### Phase 2:隱私架構基礎建設
- 確認 ZDR 申請流程
- 寫資料解析器(瀏覽器端)
- 建無狀態後端
- **這階段不過,作品論證不成立**

### Phase 3:幕二文案實作
- 用占位資料測節奏
- 確認 pause 時間自然
- 用真實資料測冷感是否成立

### Phase 4:幕一(邀請)+ 幕三(對話)+ 對話結束過場
- 串接前後端
- 加入 Ghost 對話
- 對話結束的純統計過場(分鐘、字數、「我」次數)
  - **注意:這取代了 docs/04 §1 推翻的「鏡子頁/揭露頁」。**
    不列真實服務、不塞 Charlie Brooker 問題,只用幕二的統計美學讓觀眾自己看出 mirror。

### Phase 5:幕五(結尾)
- 保持極簡
- **抗拒加東西的衝動**

### Phase 6:測試 + 開源
- 找 5-10 個朋友測試(**避開喪親、嚴重憂鬱、自殺意念者**)
- 收集情緒反應,不是 UX bug
- 公開 GitHub
- 部署

## 7. 知道何時停止

side project 最大的陷阱是「再加一點」。

每次想加東西時,問:**這個東西是讓作品更克制,還是更熱鬧?**

如果是更熱鬧——不要加。

> 「完成,然後刪掉一半。」
> ——這個專案的開發箴言

## 8. 最後

如果這個專案有一個敵人,那是 **過度設計**。

如果做出來的版本你自己都覺得「再加點什麼會不會更好」——
通常答案是「再拿掉點什麼會更好」。

祝你做出一個會讓人記住的作品。
